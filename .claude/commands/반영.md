---
description: ops_admin → ops_work 즉시 반영 (점검 통과 시에만)
---
1. `git pull --rebase`
2. `npm run check` — 실패하면 반영하지 말고 실패 내용만 보고.
3. 통과하면 `gh workflow run ops-promote` 로 즉시 반영 요청.
4. 3~10분 뒤 `npm run check:live` 로 실제 ops_work 주소 점검.
5. 실패하면 즉시 `bash tools/rollback.sh` 실행 후 보고.
결과는 한 줄: 반영 여부 · PC/MO 결과.
