# 셀렉트인 매출 앱 (보관)

> **2026-10-27: 데일리 매출 앱은 사용 중지(보관).** 매출은 셀렉트인 OPS → 매출 메뉴에서 봅니다.
> OPS 서버(`apps-script/허브.gs`의 `hubSales_`)가 매출판 시트를 직접 읽고, 매출판 대시보드 월누적과 자동 대조합니다.
> 예전 주소는 OPS 매출로 이동하며, 예전 화면 원본은 `archive/daily-sales-app/`에 보관. Apps Script `일일매출` 프로젝트(시트 자동화)는 그대로 둡니다.


셀렉트인 내부용 데일리 매출 앱 (폰 홈 화면에 설치하는 웹앱).

```
폰 앱 (docs/, GitHub Pages)  ──비밀번호/토큰──▶  Apps Script '일일매출' 웹앱 (매출앱.gs)  ──▶  데일리 매출판 시트
```

- **docs/** — 앱 화면. GitHub Pages가 이 폴더를 그대로 공개. 기간 설정·계산은 폰에서 처리, 직전 데이터는 폰에 저장해 즉시 표시
  - `config.js` — Apps Script 웹앱 주소(`…/exec`). 비밀번호 없이는 데이터가 나가지 않으므로 공개돼도 됨
- **apps-script/매출앱.gs** — 로그인 확인 + 시트 데이터 API. Apps Script `일일매출` 프로젝트의 `매출앱.gs` 파일 원본
  - 같은 프로젝트의 Code.gs·월말 메일.gs·월말정산.gs·과거채우기.gs(기존 자동화)는 건드리지 않음
  - 모든 이름에 `dr` 접두어. 이 프로젝트에서 `doPost`는 매출앱.gs에만 있어야 함
  - 시트는 읽기만 함

## 보안
- 앱 비밀번호와 서명키는 Apps Script **스크립트 속성**(`DR_PASSWORD`, `DR_SECRET`)에만 저장. 코드·저장소에는 없음
- 로그인하면 90일짜리 서명 토큰을 폰에 저장. 비밀번호를 바꾸면 모든 토큰 즉시 무효
- 비밀번호 10회 연속 오류 시 15분간 로그인 차단

## 처음 설정 (1회)
1. Apps Script `일일매출` 프로젝트의 `매출앱.gs`를 `apps-script/매출앱.gs` 내용으로 교체
2. `drSetup` 실행 → 실행 로그에 **앱 비밀번호** 표시 (10분 캐시 트리거도 함께 설치)
3. 배포 → 새 배포 → 웹 앱 / 실행: 나 / 액세스: **모든 사용자** → `…/exec` 주소를 `docs/config.js`에 기록
4. GitHub 저장소 Settings → Pages → Branch `main` / 폴더 `/docs`
5. 폰에서 `https://select-in.github.io/sales-app/` 접속 → 홈 화면에 추가

## 운영
- **화면 수정**: main에 push → 1~2분 내 자동 반영
- **매출앱.gs 수정**: Apps Script에 붙여넣고 저장 → 배포 관리 → 기존 배포 수정 → 새 버전 (주소 유지)
- **비밀번호 변경**: 프로젝트 설정 → 스크립트 속성 → `DR_PASSWORD` 수정
- **데이터 갱신**: 시트 캐시 최대 15분(10분마다 자동 갱신). 앱의 ↻ 버튼은 시트를 즉시 다시 읽음

# 셀렉트인 운영 프로그램 (제안서 · 공구 정산서 · 사입 원가표)

```
Apps Script '셀렉트인제안서및정산서' 웹앱 (운영프로그램_Code.gs)
   └─ 열 때마다 docs/ops/index.html (GitHub Pages) 최신본을 불러와 화면 표시
   └─ 데이터: 구글 드라이브 '셀렉트인 운영 프로그램 DB' 시트 (_db 탭) — 저장소엔 없음
```

- **docs/ops/index.html** — 화면 코드. main에 push하면 1~2분 내 웹앱에 자동 반영 (다시 붙여넣기·배포 불필요)
- **apps-script/운영프로그램_Code.gs** — 서버 코드 원본. 이 파일이 바뀔 때만 Apps Script에 붙여넣고 새 버전 배포
- 화면 코드에는 데이터·API 키가 없음 (키는 스크립트 속성 `ANTHROPIC_API_KEY`에만 저장)

# 셀렉트인 OPS (통합 운영 앱)

흩어진 내부 프로그램을 한 화면에 모으는 새 앱. **기존 매출 앱·운영 프로그램은 그대로 두고** 별도로 동작합니다.

```
docs/hub/ (GitHub Pages, https://select-in.github.io/sales-app/hub/)
   ──이름+PIN 토큰──▶  새 Apps Script '셀렉트인 OPS' 웹앱 (apps-script/허브.gs)
   ──▶  새 구글 시트 '셀렉트인 OPS DB' (탭: 상품 · 재고이력 · 원가이력 · 직원 · 설정)
```

- 1단계 기능: 홈(오늘 할 일·재고 경고·사방넷 스케줄러 점검 기록), 상품 관리(엑셀 붙여넣기), 재고 입출고(폰 카메라 바코드 스캔·연속 스캔), 원가·마진(원가 변동 자동 기록), 기존 프로그램 바로가기, 직원 계정 관리
- 준비 중(메뉴만 있음): 주문·발주·송장, 공동구매, 인플루언서, 매출
- `docs/hub/config.js`의 `HUB_API`가 비어 있으면 **체험 모드**(데이터가 그 기기에만 저장)

## 처음 설정 (1회)
1. 구글 드라이브에 새 스프레드시트 `셀렉트인 OPS DB` 만들기
2. 확장 프로그램 → Apps Script → `apps-script/허브.gs` 내용 붙여넣기 → 저장
3. `hubSetup` 실행 → 실행 로그에 **관리자 이름(대장)·PIN** 표시
4. 배포 → 새 배포 → 웹 앱 / 실행: 나 / 액세스: **모든 사용자** → `…/exec` 주소를 `docs/hub/config.js`의 `HUB_API`에 기록
5. 폰에서 `https://select-in.github.io/sales-app/hub/` 접속 → 홈 화면에 추가, 설정 메뉴에서 직원 추가

## 보안
- 직원별 이름 + 숫자 PIN 로그인, PIN은 해시로만 저장. 10회 틀리면 15분 잠금
- 토큰 90일. PIN을 바꾸거나 「사용 중지」하면 그 직원의 토큰 즉시 무효
- 서명키는 스크립트 속성 `HUB_SECRET`에만 저장 (hubSetup이 자동 생성). PIN 분실 시 `hubResetAdminPin` 실행
